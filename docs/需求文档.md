# 矿权日报 Agent：需求与验收基线

依据用户提供的《新建 文本文档 (2).txt》。HR 未提供其他数据、账号或补充条件；工程规范来自用户后续要求。本文记录原题、实现映射与验收边界，不增加前端、数据库、调度或生产平台等要求。

## 原题要求与实现

| 要求 | 实现 |
| --- | --- |
| mining-news-mcp | `search(query, days)`、`fetch_article(url)` |
| mineral-pdf-mcp | `extract_resources(pdf_url)`；真实 NI 43-101 的 Indicated / Inferred 抽取 |
| lme-price-mcp | `get_price(commodity, date)`、`get_trend(commodity, days)` |
| 一个 Agent client | Python 官方 SDK，自写固定流程，真实 MCP stdio 调用三个独立服务 |
| 输入与输出 | Pilbara 自然语言请求 → 新闻摘要、资源量、价格走势、风险提示和来源链接 |
| mcp-config.json | 三个 Docker stdio 启动命令，可用于 Cursor / Claude Desktop |
| RUN.md | 五分钟运行说明，包含 Docker Compose 命令与完整离线运行包 |

三个 server 是独立进程，可运行在同一容器。固定流程属于题目允许的自选编排；没有要求必须采用 LangGraph、ReAct 或指定模型。

## 数据与输出要求

- Pilbara 解析为 Pilbara Minerals / PLS 的 Pilgangoora 项目，日报明确实体。
- 新闻保留真实发布日期、来源和正文。搜索无结果或正文缺失时明确状态。
- Pilgangoora 为 JORC；Zeus NI 43-101 报告独立验证工具，不混用项目和标准。
- Indicated / Inferred 是资源量类别，不能冒充经济可采 Ore Reserves。解析保留单位、类别、有效日期、页码和原文证据。
- 价格使用真实 LME LH 工作簿，明确商品、币种、单位、日期和固定交割月份；氢氧化锂不等同项目锂辉石售价。
- 趋势至少两个同口径点，由程序计算；不插值造价，不拼接不同月份合约。
- 日报附资料日期、生成时间、分析截止日、来源列表与缺失说明。模型不能自行增加数字或引用。

当前离线演示固定在 **2021-09-08 历史回放**。它证明规定工具和编排可用，但不能据此声称完整实时“今日简报”已经验收。live 入口使用当前日期，当前行情和持续更新来源仍需补齐。原题的“今日”要求保留，不通过改写需求消除差距。

## 工程要求

实现按 CLI / Agent / MCP / provider / schema 分层；依赖锁定，Ruff、mypy strict 和 pytest 检查，真实协议集成测试与 CI 工作流。stdout 专用于 MCP 协议；诊断写 stderr；运行证据带 run_id。

密钥不进入仓库、镜像或日志。下载限定 HTTPS 来源，检查重定向、公网 DNS、体积和超时；已登记原文在 demo 与 live 中均校验哈希。容器非 root，数据只读，输出目录单独可写。

成功与业务错误使用统一状态：ok、partial、empty、error。日报 complete 仅表示所选模式证据齐全；`--strict` 在数据不完整时返回非零退出码。任何测试跳过、GUI 未测、远程 CI 未跑必须如实标明。

## 五分钟与交付验收

离线包包含源码、镜像、依赖和演示缓存。前提为 Docker 已安装启动、压缩包已在本机；计时包含解压、校验、首次导入和生成报告。用空镜像、空依赖层且断网的隔离引擎复验，不能以已有缓存的数秒结果代替首次启动证据。
