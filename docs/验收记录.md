## 首次启动证据

2026-10-09 最终运行镜像空缓存实测 **62.51 秒**：解压 1.90 秒、隔离引擎准备 17.52 秒、校验 1.87 秒、首次镜像导入 33.21 秒、日报生成 7.51 秒。精确记录及镜像身份在 `examples/startup-timing.json`；退出码 0，状态 complete。这项测试独立于已有镜像下的重复运行。

测试条件：交付 ZIP 与固定版本测试辅助镜像已在本机，Docker 已安装启动；独立引擎初始镜像数为 0、依赖层存储为空，辅助容器与 Agent 均断网，没有挂载宿主 Docker socket。日报 complete，退出码 0；测试结束清理本次辅助容器和临时卷。主 Docker 的已有业务镜像和缓存保持不变。

这验证本机离线首次运行满足五分钟目标，不包含安装 Docker 或传输 ZIP；不是对任意机器性能的保证。日常双击入口的测量单独记录在 outputs/offline-startup.json，其中会明确是否已有镜像。

Windows 双击脚本使用 .NET 流式 SHA-256 校验，避免某些 PowerShell 环境缺少 Get-FileHash 时启动失败。镜像与 Compose 在首次测试后未变更；将实测证据写入 examples 后重新封装交付包。
