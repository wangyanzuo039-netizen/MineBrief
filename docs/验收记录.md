## 复核发现与修复

- 正文下载失败时丢失已取得 RSS 摘要：已修复为保留 source_id 和摘要、返回 partial；无可用摘要时保持错误。新增三项新闻回归测试。
- live 已登记 PDF 缺少哈希校验、陌生版本可能套用固定元数据：已修复。demo/live 均验证原文哈希，未登记内容版本明确拒绝；新增三项数据回归测试。
- 原五分钟证据只有已有镜像时的 8.12 秒：已改为交付完整离线运行包，并补充空镜像、空依赖层的独立首次启动测量。
- 兼容 Docker Desktop OCI index ID 与经典引擎 config ID；离线启动同时验证归档哈希及对应镜像身份。
- 在哈希版本约束之外，对 PDF 原文的有效日期表述增加核对，支持日/月/年与月末表述；日期不符时拒绝套用登记元数据。哈希校验仍是保护登记版本的完整约束，不能仅靠正文出现某日期认定版本相同。
- 新目录重新安装依赖并生成本机路径配置，实际生成 complete 日报；工具契约通过真实 MCP tools/list 验证。
- 导出前核对镜像内全部项目源码、README、manifest 与依赖文件的哈希，防止源码和运行镜像混用不同版本。

## 首次启动证据

2026-10-09 最终运行镜像空缓存实测 **66.58 秒**：解压 1.91 秒、隔离引擎准备 17.64 秒、校验 2.36 秒、首次镜像导入 35.57 秒、日报生成 8.49 秒。精确记录及镜像身份在 `examples/startup-timing.json`；退出码 0，状态 complete。这项测试独立于已有镜像下的重复运行。

测试条件：交付 ZIP 与固定版本测试辅助镜像已在本机，Docker 已安装启动；独立引擎初始镜像数为 0、依赖层存储为空，辅助容器与 Agent 均断网，没有挂载宿主 Docker socket。日报 complete，退出码 0；测试结束清理本次辅助容器和临时卷。主 Docker 的已有业务镜像和缓存保持不变。

这验证本机离线首次运行满足五分钟目标，不包含安装 Docker 或传输 ZIP；不是对任意机器性能的保证。日常双击入口的测量单独记录在 outputs/offline-startup.json，其中会明确是否已有镜像。

Windows 双击脚本使用 .NET 流式 SHA-256 校验，避免某些 PowerShell 环境缺少 Get-FileHash 时启动失败。镜像与 Compose 在首次测试后未变更；将实测证据写入 examples 后重新封装交付包。
